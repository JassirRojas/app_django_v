# Desarrollo de Aplicaciones I - Proyecto Web

## Metodología de Desarrollo en V: Rama Descendente (Fase de Verificación)

Este proyecto sigue la fase descendente de la Metodología en V, la cual garantiza que cada etapa de diseño y análisis tenga su respectiva fase de prueba en la rama ascendente. A continuación se describe cada paso aplicado al proyecto:

* **Análisis de Requisitos (Requirement Gathering):** Se definen las necesidades del usuario y las funcionalidades del sistema. En nuestro caso, se establecen los privilegios de acceso y la necesidad de gestionar usuarios mediante roles definidos.
* **Análisis del Sistema (System Analysis):** Se especifica el comportamiento general del software y la arquitectura funcional, definiendo cómo interactuará el backend con las vistas de los distintos usuarios.
* **Diseño de Software / Arquitectura (Software Design):** Se definen los componentes principales, interfaces y tecnologías del stack, el cual estará conformado por Python, Django, Vite.js y Docker para la virtualización.
* **Diseño de Módulos (Module Design):** Se detallan la lógica interna, algoritmos y modelos de datos de cada aplicación o módulo. Aquí estructuramos la APP de registro, el inicio de sesión y la configuración del panel de administración (Django Admin).
* **Punto de Inflexión:** Transición de la planificación pura a la ejecución técnica.
* **Codificación (Coding):** Construcción del código fuente y desarrollo del proyecto, comenzando por la inicialización de contenedores y configuración del framework.
